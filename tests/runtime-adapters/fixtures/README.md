# Runtime Adapter Fixtures

These fixtures support PRD-0052A contract development. They are evidence inputs, not
production support claims and not M0/M1 qualification artifacts.

## Fixture classes

- `hermes/0.18.2-darwin-arm64-real` — generated with pinned Hermes source against an
  isolated, empty environment; contains a sanitized state tree, consistent SQLite fixture,
  and native backup.
- `openclaw/2026.6.6-darwin-arm64-real` — generated by pinned OpenClaw non-interactive
  setup; the ephemeral gateway token was replaced with the literal
  `fixture-only-not-a-secret` before the tree and native backup were captured.
- `circle-agent/0.1.0-linux-amd64-sanitized` — derived from the named committed Circle
  config shape with fixture identities, plus a fresh AgentBootup libSQL schema/database.
  This is a pre-M0 candidate and cannot satisfy M0 by itself.
- `synthetic/security/cases.json` — declarative edge cases materialized dynamically in
  tests so links, hardlinks, FIFOs, sockets, Windows paths, and collisions do not require
  unsafe or platform-specific Git entries.

## Privacy and integrity gate

Before commit, source trees were generated without inherited credentials, secret-like
content scans returned no matches, credential files were empty/reference-only, and the
OpenClaw generated token was destroyed. Do not replace fixtures with a developer's real
runtime home or copy from a dirty brain checkout.

When intentionally changing a fixture:

1. regenerate it from the exact runtime/version in a disposable root;
2. remove/generated-secret values before archive creation;
3. scan both the tree and archive members;
4. review archive membership and absolute paths manually;
5. update `fixture.json` checksums and provenance;
6. run fixture-drift, classifier, schema, and redaction tests.

The blocking deterministic checks are `bun test tests/runtime-adapters/` and
`node scripts/check-runtime-fixture-drift.mjs`. The fixture corpus and evidence documents remain
source-only test inputs; they are deliberately excluded from the npm package until a concrete
runtime consumer and a separate privacy, licensing, and size review justify distribution. The
validator also accepts an explicit absolute fixture root. Fixture metadata pins the exact source-file list and
tree digest; an unlisted addition, changed artifact, changed archive membership evidence,
machine path, or secret-shaped value fails closed. The narrowly permitted OpenClaw value
is the documented `fixture-only-not-a-secret` sentinel at JSON pointer
`/gateway/auth/token` in exactly the source `state/openclaw.json` and the native archive's
generated `.openclaw/openclaw.json` and `.openclaw/openclaw.json.bak` members. Any other
file, member, or pointer fails closed.

Native archives remain typed same-runtime evidence. Their membership does not override
AgentBootup classification or exclusions.

The materialized real trees intentionally retain observed SQLite WAL/SHM sidecars so the
classifier proves they are excluded once the corresponding primary database has a consistent
snapshot. The checked-in native archives demonstrate that both pinned native backup commands
omit those sidecars.
